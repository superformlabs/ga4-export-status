# GA4 Export Status

Public home of the **[non-official GA4 BigQuery Export Status page](https://ga4-export-status.ga4dataform.com)**, run by [GA4Dataform](https://ga4dataform.com) (Superform Labs).

The page shows whether Google's daily GA4 export to BigQuery is running late for everyone or only for you. It is built from export timings shared by connected properties, and you can subscribe to email alerts on the page.

## Report an issue or request a feature

- **Something looks wrong on the page?** [Report an issue](https://github.com/superformlabs/ga4-export-status/issues/new?template=bug-report.yml)
- **Missing a feature?** [Request a feature](https://github.com/superformlabs/ga4-export-status/issues/new?template=feature-request.yml)

Issues here are public, so you can follow progress and add your use case to existing requests. For anything private, write to support@superformlabs.eu.

## Documentation

Technical documentation (how delays are measured, what a connected property shares, how to disconnect) will be published in [`docs/`](docs/).
